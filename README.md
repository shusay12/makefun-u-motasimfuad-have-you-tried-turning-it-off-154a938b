## The entry

> Good news: I've escalated your ticket to Tier 2. Bad news: Tier 2 is me, in a different hat.

One original line (92 characters) with a sharp, surprising twist: the
escalation every desperate customer hopes for goes nowhere, because Tier 2
is the same hopeless agent in a different hat. The humour is the agent's
cheerful uselessness, never the customer — and it never leans on the
"turn it off and on again" classic at all.

## How it works

`main.py` writes the line directly to `/output/entry.txt`. It validates the
competition gate first (single line, 1–199 characters, not only whitespace,
valid UTF-8), writes the file directly, then re-reads it to confirm it
matches exactly.

```sh
python3 main.py
```
